# PrintCare — сайт + CRM для выездного сервиса принтеров

Полноценная платформа для сервиса, который заправляет картриджи и чинит принтеры с выездом: маркетинговый сайт, личный кабинет клиента и CRM с ведением заявок, аналитикой и ботами Telegram/Max.

**Стек:** Next.js 15 · TypeScript · Tailwind · Prisma (SQLite/PostgreSQL) · Framer Motion · iron-session

---

## Быстрый старт (локально, 3 минуты)

```bash
npm install
cp .env.example .env
#  -> в .env заполните SESSION_PASSWORD (любая случайная строка от 32 символов)
#     SESSION_PASSWORD можно сгенерировать так:
#     node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"

npx prisma generate
npm run db:push          # создать таблицы в dev.db (SQLite по умолчанию)
npm run db:seed          # услуги, картриджи, цены, демо-пользователи
npm run dev              # http://localhost:3000
```

Открываем `http://localhost:3000/crm/login`. Демо-доступ:

- Админ: `admin@example.ru` / `admin123`
- Мастер: `master@example.ru` / `master123`

> **Перед продом обязательно поменяйте эти пароли** — через Prisma Studio (`npx prisma studio` → таблица `User`) или дописав короткий скрипт.

## Структура проекта

### Публичный сайт

- `/` — главная: hero с mouse-tilt, услуги, калькулятор, секции «Под капотом» и «Связаться», форма заявки
- `/services/{zapravka|zamena|diagnostika|remont}` — страницы услуг с FAQ
- `/problems/{...}` — SEO-разделы по типовым проблемам: полосы, бледная печать, грязная печать, повторяющиеся дефекты, призраки, пустые листы, засохшие сопла, не захватывает бумагу, не видит картридж, тонер стирается, прошивки, и т. д.
- `/corporate`, `/price`, `/about` — корпоративным, прайс, контакты

### CRM (`/crm`)

- **Сегодня** — лента «что сейчас / дальше / опоздания / новые / ждут оплаты»
- **Доска** — kanban по статусам с drag-n-drop
- **Календарь** — день/неделя на временной оси с нерабочими днями
- **Все заявки** — фильтрация, быстрые действия по статусу
- **Аналитика** — KPI, выручка по дням, donut статусов, топ услуг и клиентов
- **История** — heatmap выполненных за год
- **Клиенты** — карточка с историей, адресами, принтерами
- **Прайс** — импорт из Excel (Услуга slug, Бренд, Модель, Цена, Заметка)
- **Нерабочие дни** — отметить выходные / праздники, видны в календаре и предупреждают клиента
- **Боты** — настройка Telegram/Max в одном окне, привязка сотрудников через deep-link

### Быстрая заявка (CRM)

В правом верхнем углу кнопка «Новая заявка» или `Ctrl+K`. На мобиле — плавающий «+» снизу. Авто-поиск клиента по телефону, кнопка «Повторить» последний заказ.

### Telegram-бот

Один бот = три сценария, определяемые по `chat_id`:

| Кто | Видит |
|---|---|
| Клиент | Wizard заявки (услуга → картридж → когда → адрес → контакт), `/status` |
| Мастер | `/today` `/next` с inline-кнопками «🚗 Выехать → ✅ Прибыл → 🏁 Завершить» |
| Админ | Меню + быстрый ввод одной строкой («Иван +79991234567 заправка HP 83A завтра Невский 25») + парсер + confirm-экран |

Уведомления клиенту шлются автоматически при смене статуса. У админов есть кнопка «🙋 Принять на себя» на новых заявках.

**Настройка** — `/crm/settings/bot`:
1. Пропишите `TELEGRAM_BOT_TOKEN` в `.env` или прямо в UI
2. Для локальной разработки: `npm run bot:poll` (без webhook, без ngrok)
3. Для прода: укажите `PUBLIC_BASE_URL` и нажмите «Зарегистрировать webhook»
4. Привязать сотрудника: кнопка «🔗 Привязать через бот» в строке сотрудника — генерится одноразовая ссылка, по клику привязка автоматическая

## База данных

По умолчанию SQLite — для prod рекомендуется PostgreSQL. Поменять — в `prisma/schema.prisma`:

```prisma
datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}
```

И `DATABASE_URL="postgresql://user:pass@host:5432/dbname"` в `.env`.

Главные модели: `User`, `Client`, `Address`, `Printer`, `Cartridge`, `Service`, `Price`, `Request`, `Message`, `ClientChannel`, `Holiday`, `ConversationState`, `PairingToken`, `RequestLead`.

## Деплой в прод (один из вариантов)

1. **VPS + Docker / pm2:** `npm run build` → `npm start`. Перед запуском поменять SQLite на Postgres, выставить `SESSION_PASSWORD` и `PUBLIC_BASE_URL`. Webhook регистрируется кнопкой в `/crm/settings/bot`.
2. **Vercel** работает, но SQLite не подойдёт — поднимите Postgres (Neon / Supabase) и пропишите URL.

## Тех. примечания

- Auth: `iron-session`, cookie. Защита `/crm/*` — `src/middleware.ts`
- Тёмная тема по умолчанию, единая палитра в `src/app/globals.css`
- Анимации: Framer Motion + CSS, без WebGL
- Адаптивно: mobile-first, нижняя навигация в CRM на мобилке, плавающий «+»
- Цвета статусов и переходы между ними — один файл `src/lib/status.ts`
- Адаптер мессенджеров — `src/lib/messengers/`. Стаб Max активируется заменой URL/payload в `max.ts` без правки flow-кода
- Уведомления админам — `src/lib/bot/notify.ts`, рассылаются по `User.role=ADMIN` + `TELEGRAM_ADMIN_CHAT_ID`, дедуплицируются
